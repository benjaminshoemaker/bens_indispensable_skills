# Canonical ownership and reuse

This repository is the source of truth for reusable personal skills. Installed client copies and contextual implementations in other workspaces do not replace it. Edit the generic implementation here, verify its supporting files and installer, then explicitly refresh the selected installation.

The newly selected workflows are `iterate-prompts`, `prepare-pr`, and `google-doc-structure`. Each is self-contained under skills/; the prompt comparison template ships with iterate-prompts. No broader workflow pack is implied. Existing catalog entries remain available.

Keep personal career evidence and interview delivery in the private interview workspace. Keep PM operating methods and tool maintenance in the private PM workspace. Link to the public skill from those workspaces; do not embed private provenance or organization-specific instructions here.

See [installation strategy](installation-strategy.md) for copied installations and [compatibility](compatibility.md) for execution requirements. Reuse depends on the current project’s available tools and permissions; a generic skill does not carry company access or publishing authority.
