# Comparison record

Use these fields where they matter; reuse an existing experiment record.

- Target behavior and preserved contract
- Baseline and candidate versions; exact edit and review status
- Input source and permitted scope; effective date and existing state
- Runtime/model/settings; tool and retrieval substitutions; persistence target
- Development cases, independent cases, repeats, and reset method
- Paired final outputs and saved/readback evidence
- Useful results, omissions, abstentions, errors, timeouts, and denominators
- Human judgments versus agent assessments
- Keep, revise, reject, or defer; uncertainty and next action

Synthetic example: an assistant generates a checklist for a fictional export task. The baseline adds unrelated safeguards. The candidate preserves the required access boundary while dropping the extra item. Review scope preservation and saved status, not just checklist length.
