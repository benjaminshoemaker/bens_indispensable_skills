# Personal skills library

This repository owns the canonical generic implementations under skills/. Preserve the public, provider-independent scope and existing selective installer. Agent-home copies and other repositories’ contextual variants are not upstream sources.

Before changing a skill, compare its current implementation and required supporting files; preserve substantive improvements and avoid parallel versions. Validate the relevant packaging and links. Do not copy private career provenance, company prompts, source data, credentials or workspace paths into public files.

Keep explanation, setup and compatibility guidance in docs/; keep executable instructions and required resources with the skill. The library is a catalog, not a mandatory delivery workflow. Publishing or pushing requires the user’s specific authorization; local preparation does not authorize it.
